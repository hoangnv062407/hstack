hstack dùng chung các skill và playbook kỹ thuật trên Cursor, Claude Code, Codex CLI và Antigravity. Benny bổ sung luồng xử lý ticket Help Scout trên Shopify staging.

| Hiểu adapter chọn lệnh, agent và worktree thế nào | [Adapter theo harness](harness/README.md) |
| Kiểm chứng bản sửa và chuẩn bị draft PR | [03 · Kiểm chứng và mở draft PR](guide/03-kiem-chung.md) |
| Chạy một ca Help Scout qua Benny | [04 · Luồng Benny](guide/04-benny.md) |
| Thêm skill hoặc đổi adapter | [05 · Tùy chỉnh hstack](guide/05-tuy-chinh.md) |
| Xử lý lỗi cài đặt, MCP hoặc staging | [06 · Xử lý sự cố](guide/06-xu-ly-su-co.md) |

Cách tổ chức tài liệu dựa trên [pstack docs](https://github.com/cursor/plugins/tree/main/pstack/docs). Các lệnh, đường dẫn và quy tắc vận hành trong bộ này áp dụng cho hstack.
